# Finanzas Pro CL

Conversor de monedas, metales y criptomonedas con indicadores chilenos (UF, UTM, dólar, IPC, TPM, cobre),
gráficos históricos y 47 herramientas: UTM/UF/IPC, multas y trámites, impuestos (IVA, honorarios, F29,
Operación Renta), sueldo y trabajo, créditos y ahorro, calendario tributario, oro y plata.

App: https://doclam2015-create.github.io/finanzas-cl/

Datos oficiales y gratuitos, sin claves ni backend: Banco Central y SII (mindicador.cl), INE, Dirección del
Trabajo, Superintendencia de Pensiones, open.er-api.com, CoinGecko/Binance, gold-api.com.

## Widget para iPhone (Scriptable)

Archivo: [`widget-finanzas-cl.js`](widget-finanzas-cl.js) · enlace directo:
https://raw.githubusercontent.com/doclam2015-create/finanzas-cl/main/widget-finanzas-cl.js

1. Instala **Scriptable** (gratis, App Store).
2. Crea un script nuevo llamado `Finanzas CL` y pega el contenido del archivo.
3. Mantén pulsada la pantalla de inicio → **+** → Scriptable → elige tamaño (pequeño, mediano o grande).
4. En el widget: **Script** = Finanzas CL · **When Interacting** = Open URL.

Muestra dólar (con variación diaria), euro, UF, UTM/UTA, bitcoin, oro, cobre, IPC del INE y los próximos
vencimientos de F29 y cotizaciones, corridos al día hábil siguiente por feriados.
